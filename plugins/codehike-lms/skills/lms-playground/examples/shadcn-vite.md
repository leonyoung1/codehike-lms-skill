# Example: shadcn/ui playground (post-init state)

**Task:** Scaffold a code playground for a lesson on React component libraries using shadcn/ui. Students start from a working generated Button and are asked to generate more components themselves with the shadcn CLI in the terminal. The project must be shadcn-capable on first load — which means it ships the post-`shadcn init` state, because `init` cannot run inside the sandbox (its /init theme-config endpoint is unreachable from WebContainer egress).

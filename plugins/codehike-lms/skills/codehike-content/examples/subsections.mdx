<Subsection type="activity" title="Build a countdown timer"/>

### Start from the target value

The state holds how many seconds are left. Zero means the timer has finished.

```js timer.js -nc
let secondsLeft = 3;
```

### Tick once per second

Each tick subtracts one and stops at zero, so the interval never runs negative.

```js timer.js -nc
setInterval(() => {
  if (secondsLeft > 0) {
    secondsLeft -= 1;
  }
}, 1000);
```
